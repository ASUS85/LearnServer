DEPLOIEMENT LOCAL - PROJET LEARNSERVER
Date: 2026-07-16
Environnement cible: Windows + WAMP

1) PREREQUIS
- WAMP installe (Apache + PHP + MySQL/MariaDB)
- Navigateur web
- Acces a phpMyAdmin

2) PLACEMENT DU PROJET
- Copier le dossier LearnServer dans:
  c:\wamp64\www\LearnServer
- Verifier que ces fichiers existent a la racine:
  index.php, register.php, README.md

3) DEMARRAGE DES SERVICES
- Ouvrir WAMP
- Demarrer Apache et MySQL
- Verifier l'icone WAMP en vert

4) CREATION DE LA BASE DE DONNEES
- Ouvrir phpMyAdmin: http://localhost/phpmyadmin
- Creer une base de données: gestion_cours_db
- Importer le script SQL du projet:
  database/init_learnserver.sql

4.1) IMPORT SQL (METHODE RECOMMANDEE)
- Dans phpMyAdmin, selectionner la base: gestion_cours_db
- Ouvrir l'onglet Importer
- Choisir le fichier:
  c:\wamp64\www\LearnServer\database\init_learnserver.sql
- Lancer l'import
- Verifier que les tables suivantes existent:
  admins, enseignants, etudiants, filieres, niveaux, classes,
  matieres, emplois_temps, notes

5) CONFIGURATION DE LA CONNEXION BDD
- Verifier/editer les fichiers:
  config/database.php
  app/config/database.php
- Parametres conseilles en local:
  host: localhost
  port: 3306
  username: root
  password: (vide par defaut WAMP)
  database: gestion_cours_db

6) URLS DE TEST
- Point d'entree principal:
  http://localhost/LearnServer/
- Route publique MVC (si active):
  http://localhost/LearnServer/public/
- Login API (selon implementation):
  http://localhost/LearnServer/api/login.php
